プライバシーポリシー

最終更新: 2026年8月30日

1. 運営者

本アプリ「ozawa-threads-autopost」（以下「本アプリ」）は、運営者（連絡先: owaso@msn.com）が提供します。本アプリは、運営者自身の Threads アカウント運用を目的とした自動投稿・分析ツールです。

2. 取得する情報

本アプリは、利用者が Threads で許可した範囲で次の情報を取得することがあります。

  • Threads のユーザー ID、ユーザー名
  • 本アプリが作成・公開した投稿の本文、投稿 ID、公開日時
  • 自投稿のインサイト（表示、いいね、リプライ、シェア、リンククリック等）
  • 利用者が許可したキーワード検索結果（公開投稿の本文、投稿時刻、パーマリンク、リプライ構成）
  • 投稿文の生成に必要な入力テキスト（ニュース見出し、分析結果、商品名など）

3. 利用目的

  • Threads への投稿・リプライ投稿
  • 伸びている投稿の型を分析し、運営者の投稿品質を改善する
  • 暮らしと防災に関する商品情報の表示（楽天アフィリエイト / Amazon アソシエイト）
  • 障害調査、セキュリティ、法令遵守

取得した情報を、上記以外の広告ネットワークへ販売したり、無関係な第三者へ提供したりしません。

4. 外部サービスへの送信

目的達成のため、次のサービスへ必要な範囲でデータを送ります。

  • Meta / Threads API（認証、投稿、検索、インサイト）
  • OpenAI API（投稿文の生成）
  • 楽天ウェブサービス、Amazon アソシエイト / Product Advertising API（商品情報とアフィリエイトリンク）
  • GitHub（ソースコードと運用データの保存、GitHub Actions での定期実行）

各サービスの取扱いは、それぞれのプライバシーポリシーに従います。

5. 保管場所と期間

投稿履歴・分析結果は、GitHub リポジトリ上の運用データおよび GitHub Actions のログに保管することがあります。運用に必要な期間保持し、削除依頼があった場合は「ユーザーデータの削除手順」に従って対応します。

6. 共有

法令に基づく場合、またはサービス提供に必要な業務委託先（上記外部サービス）を除き、個人を識別できる情報を第三者に提供しません。

7. データの削除

利用者は、本アプリが保持するデータの削除を請求できます。手順は ユーザーデータの削除手順 を見てください。Threads 側の連携解除は、Threads / Meta の設定からも行えます。
