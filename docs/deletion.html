ユーザーデータの削除手順

最終更新: 2026年8月30日

本アプリ「ozawa-threads-autopost」が保持するデータの削除を希望する場合は、次の手順で依頼してください。このページは Meta アプリ設定の「データの削除手順URL」に対応します。

1. メールで依頼する

  1. 件名を「データ削除依頼」にして、owaso@msn.com に送る
  2. 本文に、Threads のユーザー名（@なし可）または Threads User ID を書く
  3. 削除してほしい範囲があれば書く（例: 投稿履歴すべて、分析データ）

2. こちらで行うこと

本人確認のうえで、GitHub 上の運用データ（投稿履歴、分析結果、関連ログのうち特定できるもの）から該当データを削除します。目安は依頼受領から 7 日以内です。完了したら同じメールアドレスへ返信します。

3. Threads / Meta 側で自分で解除する

本アプリへのアクセス許可を自分で切る場合は、Threads または Meta のアカウント設定からアプリ連携を解除してください。解除後、本アプリは新しいデータにアクセスできなくなります。すでに保存したデータの削除は、上記メール依頼が必要です。
